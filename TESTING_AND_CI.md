# TEST_STRATEJISI_ONERISI (TESTING_AND_CI)

Hocam, sunum gününde mahcup olmamak adına şöyle bir test stratejisi öneriyorum:

## 1. Otomasyon (CI)
GitHub Actions kullanarak, ben her kod attığımda sunucunun otomatik test yapmasını sağlamak istiyorum. Bu, hataları erken fark etmemizi sağlar.

## 2. Test Kapsamı
- **Birim Testleri**: Küçük parçaların testi.
- **Entegrasyon Testleri**: Ajanın editörle uyumunun testi.
- **Uçtan Uca (E2E)**: Kullanıcı deneyiminin komple testi.
